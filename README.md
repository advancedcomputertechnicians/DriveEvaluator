# DriveEvaluator — Ontario G2 & G Road Test Scoring Simulator

DriveEvaluator is a professional, interactive digital evaluator and scoring sheet simulator designed for Ontario driving instructors, driving schools, and G2/G road test candidates.

---

## Key Features

- **Interactive Touch Scoring Sheet**: Touch-optimized scoring UI covering standard evaluation categories (Observation, Space Margin, Speed Control, Signaling, Turning, Parking, Lane Changes, Highway Driving).
- **Automated Pass/Fail & Demerit Engine**: Automatically calculates minor errors, major errors, and critical safety faults (immediate fails) with real-time pass/fail recommendations based on standard road test evaluation thresholds.
- **Embedded Highway Traffic Act (HTA) Rules**: Provides exact legal statute references (e.g., HTA s.142(1) for shoulder checks) for checklist items.
- **Multilingual Support (4 Languages)**: Full localization in English, Chinese (中文), French (Français), and Hindi (हिंदी).
- **Student Progress & Report Export**: Log test histories, examiner notes, retest wait times, and export customizable evaluation summaries.
- **Cross-Platform (Web & Mobile)**: Built with React 19 + Vite and packaged with Capacitor for native Android and iOS mobile deployment.
